# Ancore Landing Page

Marketing site for [Ancore](https://github.com/ancore-org/ancore) — an open-source account abstraction and financial UX layer for the Stellar network.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- Fly.io design system

Page copy lives in [`lib/content.ts`](lib/content.ts).
